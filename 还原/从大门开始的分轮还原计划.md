# 从大门开始的分轮还原计划

以[大门逐图校准后的 Blender 母版](成果/大门逐图校准/校园室外_大门逐图校准.blend)为起点。大门已有正面、两侧门房、门内回望和铺地对照，这次先沿门内的轴线继续往里。下面三轮是接下来的实景校准批次，现有模型作为底稿。

路线按[航拍底图](成果/第2轮/航拍重投影.png)、[总平面图](成果/第2轮/校园总平面.png)和[全景热点表](../数据/02_元数据/hotspots.csv)编排。箭头表示建模和验收的步行方向。热点能说明全景之间的视线与跳转关系。室内的门、楼层和走廊仍需结合画面核对，跳转前后的房间只在位置有依据时接通。

## 第1轮｜进大门，走完整条教学主轴

**步行主线**　03 大门口 → 穿过门楼，在门内回望 → 05 尚德广场，从喷泉侧边绕行 → 40 艺远楼与识远楼，走过连廊下方 → 45 知远楼 → 36 行远楼 → 32 图书馆入口。

| 经过位置 | 本轮复原内容 |
| --- | --- |
| 03 大门口，进门前可侧看 04 荣誉墙再回到门口 | 复核门楼、铁门、两侧门房和门岗的比例。补荣誉墙转角、墙脚和实拍牌面，检查校门内外地坪缝、排水盖及与道路交界。 |
| 05 尚德广场 | 做细喷泉池边和水面、景石、池两侧通道、树池、宣传栏与灯杆。沿行走方向连续核对石板拼缝及进门后的视线。 |
| 40 艺远楼与识远楼 | 按正反视和仰视校棚梁间距、桥底、玻璃斜撑、两翼黄墙与侧廊开口。两翼临主轴的首层窗墙、台阶和道路边沿一并对齐。按该站热点分别查看 19 会议室 → 20 党建活动室，以及 41 舞蹈排练厅 → 42 健美操排练厅 → 43 管乐排练厅 → 44 美术画室。分别补会议桌、展板、镜墙把杆、体操垫、谱架和画架等可辨认物件。 |
| 45 知远楼 → 36 行远楼 | 校准两楼黄色端墙、条窗、阳台、楼名、入口和两楼间的低层连廊。补主轴方形树池、修枝树、矮篱、井盖和石板，核对从两个站点看回大门和看向图书馆的轮廓。行远楼室内按 37 生物实验室 → 38 信息教室 → 39 录播室细化实验桌、水槽、电脑桌和录播陈设。 |
| 32 图书馆 | 保留正立面实拍牌匾和电子屏，复核台阶、栏杆、入口平台及广场前沿。用斜视补清晰可见的侧面。室内按 33 阅览室 → 34 学生发展指导中心 → 35 报告厅细化书架桌椅、阶梯看台和台前设备。 |

**当轮验收**　从门外走到图书馆台阶前。每个转折处各留向前和回望对照，重点看进门后喷泉和连廊能否对位、四处楼前是否保持连贯视线。室内房间按各自原图验收，实际连接关系待复核的继续在独立场景中查看。

**沿线进度**　尚德广场北缘到图书馆正门已接入同一份[校园母版](成果/尚德至图书馆实拍细化/校园室外_尚德至图书馆细化.blend)。连廊、知远楼前、行远楼前和图书馆前分别用各站全景展开石板贴图。图书馆台阶、树阵、石钵与分类站留有正向和两侧对照。贴图取样点记在[实拍来源与路线](成果/尚德至图书馆实拍细化/实拍来源与路线.json)。相机位与地物尺寸按航拍和照片估算。

**当轮验收**　从樱花园走到乒乓球场，核对沿线砖径、路缘和植被是否接得上。操场沿边和看台对照各留一张，草皮纹理按原图截取，跑道分线和球场标线按场地位置定位。

| 经过位置 | 本轮复原内容 |
| --- | --- |
| 22 餐厅入口 → 23 就餐区 → 24 餐厅出口 | 校两个门厅的位置、招牌、落客地坪和标线。室内补档口、餐桌排凳、顶棚管线和通道朝向，按出入口画面复核门位。 |

| 25 绅远楼 → 28 蕙远楼 | 校准两栋公寓各自的窗列、玻璃门廊、台阶及坡道。分别进入 26 男生公寓楼大厅 → 27 男生宿舍，以及 29 女生公寓楼大厅 → 30 女生宿舍，核对显示屏、床架、柜子和窗位。两栋楼之间补人行道、树池、导视和分类站。 |

**当轮验收**　从餐厅入口走到西门与劳动基地，核对餐厅进出路径和公寓坡道，逐段检查道路衔接。用 01 北侧航拍、02 正上方航拍复核三轮交界和全校总图。碰撞与漫游验收沿同一条步行路线进行，室内门位证据不足时在覆盖表标为独立场景。

## 每站怎么做

1. 打开该站720云全景。先截向前、左右和回望，再低头截铺地与井盖。檐口、树冠和连廊补仰视。用[逐文件图片索引](图片逐文件索引.csv)找高分辨率原图和邻站交叉视角。
2. 先把入口、道路边线、转角和高差落到总图，再做近景。铺地、草皮和大块墙面用校正后的实拍纹理。台阶、路缘、门窗、梁柱、近景树干和设施保留立体网格。
3. 每站保存网页截图和对应模型视角，记录贴图来源、尺寸依据及待核实项。每轮交付更新的 Blender 母版、GLB 和实景对照，将状态同步到[45场景分类表](45场景分类与细化顺序.csv)。
